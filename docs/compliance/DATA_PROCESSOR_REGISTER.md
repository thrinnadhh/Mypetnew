## Procurement control checklist

Every processor must have an accountable owner and written evidence for confidentiality, purpose limitation, access controls, encryption, key responsibility, incident notification fast enough for MyPet's six-hour CERT-In clock, subprocessor notice, country/region, retention, deletion/return, backup deletion, audit/evidence rights, regulatory assistance and termination. Code cannot satisfy this checklist.

`LEGAL/PROCUREMENT_ACTION_REQUIRED`: execute and retain approved DPAs/terms; select India-region core storage where feasible; verify no contract prevents CERT-In/Board cooperation; ensure foreign government access/DPDP transfer orders are monitored; document rejection or risk acceptance by the release owner.
